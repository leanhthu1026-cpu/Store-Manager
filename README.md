This practice asks to build an iOS app that manages an online fish store that allows users to browse a curated list of aquatic products, search for items by keyword, view product details organized by category, add products to a shopping cart with quantity controls, mark favorites, select a delivery address, place orders, and track order history. The app also includes an account screen with store location on a map, and a promotional banner on the home screen to highlight the current discounts.

### Features
- 🏠 **Home**: Promotional banner, category shortcuts, and featured products.
- 🔍 **Search**: Search products by name and description with live results.
- 📂 **Categories**: Browse products grouped by 10 categories (fish, plants, accessories, etc.).
- ❤️ **Favorites**: Mark and view favorite products.
- 🛒 **Cart**: Add, remove, and adjust quantity; dynamic total calculation.
- 📦 **Orders**: Place orders and view order history with status.
- 📍 **Location**: Select delivery address and view store location on a map.
- 👤 **Account**: User profile, store info, and support links.
